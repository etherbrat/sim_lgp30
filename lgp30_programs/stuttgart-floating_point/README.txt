According to the LGP-30 Subroutine Manual, 10-5-60, the floating point libraries comprise the following:

* 24.0 Floating Point Interpretive System (arithmetic, logic, address modification, auxiliary instructions, square root) 
* 11.6-12.6 Input-Output
* 14.1 Sine-Cosine
* 16.2 Arctangent
* 18.1 Logarithm
* 17.1 Exponential

Of these only 24.0 and 11.6-12.6 are available (by those names) in the Stuttgart repository.

The Subroutine Manual and the Floating Point Interpretive System Manual contained detailed usage instructions.
